# OlingoBot — Telegram Quiz Bot

Телеграм-бот для проведения онлайн-викторины. Викторина состоит из 5 блоков по 10 вопросов. Администратор управляет отправкой вопросов, ответы участников сохраняются в Excel-файл с временными метками.

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Скопируйте `.env.example` в `.env` и заполните:

```bash
cp .env.example .env
```

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен бота от BotFather |
| `ADMIN_IDS` | ID администраторов через запятую |
| `QUESTION_TIME_LIMIT` | Время на ответ в секундах (по умолчанию 30) |
| `EXCEL_FILE` | Путь к файлу результатов (по умолчанию `results.xlsx`) |
| `QUESTIONS_FILE` | Путь к JSON с вопросами (по умолчанию `questions.json`) |

Узнать свой Telegram ID можно через бота [@userinfobot](https://t.me/userinfobot).

## Запуск

```bash
# С переменными окружения из .env:
export $(cat .env | xargs) && python bot.py

# Или напрямую:
BOT_TOKEN=... ADMIN_IDS=... python bot.py
```

## Команды

### Для участников
- `/start` — регистрация в викторине

### Для администратора
- `/send_block <номер>` — отправить блок вопросов (1–5) всем участникам
- `/send_question <блок> <вопрос>` — отправить один конкретный вопрос
- `/participants` — список зарегистрированных участников
- `/results` — скачать Excel-файл с результатами
- `/standings` — текущая таблица лидеров

## Формат вопросов

Вопросы хранятся в `questions.json`. Структура:

```json
{
  "blocks": [
    {
      "name": "Название блока",
      "questions": [
        {
          "id": 1,
          "text": "Текст вопроса?",
          "options": ["Вариант A", "Вариант B", "Вариант C", "Вариант D"],
          "answer": 1
        }
      ]
    }
  ]
}
```

Поле `answer` — индекс правильного ответа (0–3).

## Excel-отчёт

Файл `results.xlsx` содержит столбцы:
- User ID, Имя, Username
- Блок, Номер вопроса, Текст вопроса
- Выбранный ответ, Правильный?, Время ответа (UTC)
