# OlingoBot — Telegram Quiz Bot

Телеграм-бот для проведения онлайн-викторины. 7 тематических блоков, 57 вопросов. Администратор управляет отправкой вопросов, ответы участников сохраняются в Excel с временными метками.

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Скопируйте `.env.example` в `.env` и заполните:

```bash
cp .env.example .env
```

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен бота от BotFather |
| `ADMIN_IDS` | ID администраторов через запятую |
| `EXCEL_FILE` | Путь к файлу результатов (по умолчанию `results.xlsx`) |
| `QUESTIONS_FILE` | Путь к JSON с вопросами (по умолчанию `questions.json`) |

Узнать свой Telegram ID можно через бота [@userinfobot](https://t.me/userinfobot).

## Запуск

```bash
export $(cat .env | xargs) && python bot.py
```

## Команды

### Для участников
- `/start` — регистрация в викторине

### Для администратора
- `/send_next_question` — отправить следующий вопрос по порядку
- `/send_question <блок> <вопрос>` — отправить конкретный вопрос (например: `/send_question 7 11a`)
- `/results` — скачать Excel-файл с результатами

## Типы вопросов

- **С вариантами ответа** (choice) — участник нажимает кнопку A/B/C/D
- **Открытый** (open) — участник пишет ответ текстом

## Excel-отчёт

Файл `results.xlsx` содержит столбцы:

| Столбец | Описание |
|---|---|
| Имя | Имя участника в Telegram |
| Username | @username участника |
| User ID | Числовой ID |
| Блок | Название блока |
| Вопрос № | Номер вопроса в блоке |
| Текст вопроса | Полный текст вопроса |
| Ответ | Выбранный вариант или текст ответа |
| Вопрос отправлен (UTC) | Когда вопрос был разослан участникам |
| Ответ получен (UTC) | Когда участник ответил |
